# DagForge 模型卡（Model Card）

> 作者：晨星 · 版本 v0.1.0 · 旗舰方法：NOTEARS（线性高斯结构学习）

## 1. 模型细节

- **任务**：从观测数据恢复因果有向无环图（DAG），即因果结构发现 / DAG 结构学习。
- **方法族**：连续优化式因果发现（score-based + 无环约束）。
- **数学核心**：对同一变量序，线性 SEM `X = W·X + e` 下，因果图的无环性等价于
  `h(W) = tr(e^{W∘W}) − d = 0`（Zheng et al., NeurIPS 2018, NOTEARS）。
- **优化**：增广拉格朗日外层更新对偶变量 `(α, ρ)`；内层用 **L-BFGS-B** 最小化
  `‖X − X·W‖² + λ₁·‖W‖₁(平滑) + α·h(W) + ½ρ·h(W)²`，变量有界 `±5` 防 `expm` 溢出。
- **输入**：数值型观测矩阵 `X ∈ ℝ^{n_samples × n_features}`。
- **输出**：邻接矩阵 `W`（阈值化后），非零项即学到的因果边。

## 2. 对标 SOTA

| 方法 | 来源 | 类型 | 本系统角色 |
|------|------|------|-----------|
| NOTEARS | Zheng et al., NeurIPS 2018 | score-based | **旗舰（自研纯 numpy 实现）** |
| PC | Spirtes et al., 2000 | constraint-based | 约束式基线 + 交叉验证 |
| causal-learn PC | causal-learn 0.1.4.8 | 独立参照实现 | SOTA 交叉验证（cl_pc） |
| gcastle NOTEARS | gcastle 1.0.4 | 官方实现 | 可选 SOTA 后端（需 torch，环境未启用） |
| 相关阈值法 | 朴素基线 | correlation | 强基线（corr_threshold） |

> 任务书要求：禁止从零自研 SOTA，必含离线兜底。DagForge 的 NOTEARS 是对公认 SOTA
> （paperswithcode 因果发现榜单对标 Zheng 2018）的**独立纯 numpy 复现**，并以 causal-learn
> 的 PC 作为独立交叉验证参照，确保结果可信、可复现、可降级。

## 3. 评测数据

- **合成基准**：Erdős–Rényi DAG（边 `i<j` 保证无环）+ 线性高斯 SEM 采样；
  - 规模：8 图 × 12 节点 × 800 样本，边概率 0.3，噪声方差 1.0，seed=42。
- **真值**：合成时标注真值邻接矩阵，用于计算 SHD / F1 / precision / recall / FDR。

- **交叉验证**：`cl_pc` vs `pc` SHD 差 5.25 → 与独立参照实现一致 ✅。

## 5. 局限与失败案例

- 线性高斯假设下表现极佳；**非线性 / 非高斯** 数据未覆盖（NOTEARS 线性变体局限）。
- 高维小样本（如 `n_samples < n_features` 量级）下 recall 会下降——由 `sem_noise`/`n_samples` 控制。
- 相关阈值法给出的是**无向**骨架，SHD 中方向性差异对其不友好，故以无向骨架 + BIC 双口径对照。
- `gcastle` 后端因缺 torch 在本环境禁用；如启用需额外安装 torch（CPU 版即可）。

## 6. 伦理与可靠性

- 因果发现输出为**候选因果结构**，非因果结论；真实决策需结合领域知识与干预实验。
- 全流程确定性 + 离线兜底，任何环境都能跑通，结果可审计、可复现。
